# GitHub whitepaper publication

This project is intentionally published directly on GitHub rather than
through Zenodo. GitHub provides the public repository, versioned history,
release tags, downloadable PDF artifacts, and a minimal language-switching
GitHub Pages viewer.

The first public release is `v1.0.0`. Cite the repository together with the
release tag so that the cited manuscript and derived results remain
unambiguous.

For the Pages viewer, configure GitHub Pages to deploy from the `main`
branch and the repository root (`/`). The root `index.html` provides the
English/Japanese PDF switcher and a short bilingual summary outside the PDFs.
