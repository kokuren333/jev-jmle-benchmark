# Whitepaper contents

This directory contains the public whitepaper and the reproducibility
materials that support it.

## Canonical files

- `manuscript_en.md`: English readable source.
- `whitepaper/Jev_JMLE_Whitepaper_EN_v1.0.pdf`: English PDF.
- `whitepaper/Jev_JMLE_Whitepaper_JA_v1.0.pdf`: Japanese PDF.
- `figures/final/`: figures used by the current whitepaper.
- `tables/`: source tables and derived summaries.
- `references.md`: reference list.
- `terminology_report_ja.md`: Japanese terminology guide source.

Files under `figures/legacy/` are retained only for historical traceability
and are not used by the current whitepaper.

The PDFs are the typeset publication artifacts. The English Markdown file is
intended for inspection and reuse; its image paths point to the final
figures in this directory. The earlier Japanese Markdown extraction is not
part of the public release because it is not a reliable source document.
