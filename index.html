Jev x Japanese Medical Licensing Examination benchmark

GitHub Whitepaper v1.0.0: a nine-year evaluation of information sufficiency, selective prediction, accuracy, latency, and recorded API cost.

  • 3,556 option-choice items; exact-set accuracy 88.58% (3,150/3,556)
  • Single-select AUROC 0.918; held-out selective accuracy 99.00% at 67.6% coverage
  • Median API latency 820.7 ms; recorded API cost US$0.120
This is a constrained benchmark, not a demonstration of autonomous clinical competence or prospective clinical safety.
